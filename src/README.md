# Project Name: FitLog

## Short Description
FitLog is a fitness and exercise tracking website designed to help users stay active and maintain a healthy lifestyle. It allows users to explore various exercises, calculate estimated calories burned, follow personalized workout plans, track their fitness activities, and learn useful health and fitness tips. The goal of FitLog is to make fitness management simple, engaging, and accessible for everyone.

## Technologies Used
- **Next.js** – For building the web application and managing pages.
- **React.js** – For creating reusable and interactive UI components.
- **TypeScript** – For type-safe and maintainable code.
- **Tailwind CSS** – For designing a modern and responsive user interface.
- **JavaScript** – For implementing interactive functionality and calculations.
- **JSON** – For storing and managing exercise and workout data.
- **Git & GitHub** – For version control and project management.
- **DaisyUI** – For ready-made UI components.
- **react-toastify** – For ready-made notifications.
- **react-icons** – For interactive and dynamic UI icons.

## Key Features
- **Exercise Library** – Explore a variety of exercises with workout details and instructions.
- **Calorie Calculator** – Estimate calories burned based on exercise type, duration, and user information.
- **Workout Plans** – Follow structured workout plans suitable for different fitness levels.
- **Workout Tracker** – Track daily exercises, workout duration, and fitness progress.
- **Fitness Tips** – Discover useful tips for exercise, healthy habits, and maintaining an active lifestyle.
